# Matrix-Challenger
一个面向科研的数据处理自动化助手
光谱数据处理前端。双击 index.html 即可打开。源码可以直接放进 GitHub 仓库根目录，无需安装前端依赖或执行构建命令。
当前交互
- 拖入或浏览选择 .xlsx / .xls 文件，查看文件列表并移除文件。
- 点击「试用示例」或「运行示例流程」，查看三个演示阶段的进度。
- 在「图表」和「结果表」之间切换。图表支持切换曲线，悬停或使用方向键查看光谱点。
- 下载一份包含示例光谱数据的 .xlsx，以及当前曲线的 .png 图。
所选文件保存在当前网页内存中。预览、进度和下载均使用内置模拟数据。
接入计算代码
app.js 里的 analyzeFiles(files, progress) 是计算入口。接入 Python 服务时，将 File[] 通过 FormData 发送给服务，把返回的结果整理成按波长升序排列的行。每行包含 wavelength、`raw` 和 corrected 三个数字字段。返回值同时供结果表、图表和 Excel 导出使用。接入后按实验口径更新纵轴范围、单位、处理步骤和结果标签。

export.js 处理 XLSX 打包和浏览器下载，`styles.css` 定义深色界面与手机布局。
